
# DeepDive Scholar

Structured research, backed by real-time facts.

## Features

- **Structured Mini-Report** with Executive Summary, Definitions, History, Applications, Pros & Cons.
- **Inline Citations** + **Status Checks** (✅/❌).
- **Further Reading** via Sonar Search.
- **Chain-of-Thought Transparency** in collapsible section.
- **History** of last 20 queries.
- **PDF Export** & **Copy Markdown**.
- **Multilingual** answers.
- **Compare Mode**: side-by-side topic comparison.
- **Bias Warnings** for uncited long statements.
- **Feedback** (👍/👎 + comment).

## Setup

1. **Clone** this repo.
2. `cd deepdive_scholar`
3. `pip install -r requirements.txt`
4. Copy `.env.example`→`.env`, fill in your `PERPLEXITY_API_KEY`.
5. `python run.py`
6. Open 👉 `http://localhost:7860`

Enjoy your DeepDive!
